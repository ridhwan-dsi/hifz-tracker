# Hifz Tracker

Personal Qur'an memorisation tracker. It's an installable web app (PWA) hosted on GitHub Pages.

- **Pages:** Madani mushaf, 604 pages, in `pages/` (full resolution, cached on the device).
- **Data:** each user's progress, crops and masks are saved in that user's own Google Drive (hidden app folder) after Google sign-in. Before sign-in they're saved in the browser only.
- **Config:** the Google OAuth client ID goes in `js/config.js`.

Live: https://ridhwan-dsi.github.io/hifz-tracker/
